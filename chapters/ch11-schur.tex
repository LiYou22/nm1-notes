\section{Recap and Motivation}

Lecture 10 gave methods that compute \emph{one} eigenpair: power iteration, inverse iteration and Rayleigh quotient iteration. Now we want \emph{all} eigenpairs: we ask how to compute them efficiently, and what single object should describe them.

The plan of this chapter:
\begin{enumerate}
  \item \emph{Deflation} (\Cref{sec:deflation}) removes an eigenpair we already know, so we can compute the eigenpairs one by one.
  \item This is slow. Iterating on many vectors at once is faster (\Cref{sec:subspace-motivation}). So we want all eigenpairs as one matrix factorization.
  \item The eigenvalue decomposition $A = X\Lambda X^{-1}$ does not always exist (\Cref{sec:eig-factorization,sec:defective}).
  \item The Jordan form always exists, but it is unstable (\Cref{sec:jordan}).
  \item The Schur factorization $A = QTQ^\ast$ always exists and is stable (\Cref{sec:schur-fact}). It is the right object.
\end{enumerate}

\section{Deflation}
\label{sec:deflation}

We have a fast way to compute one eigenpair. What if we want all of them?

Suppose we have computed the largest eigenpair $(\lambda_1, \vec{x}_1)$. If we run power iteration again, it finds $\vec{x}_1$ again. How do we avoid computing the same thing twice?

The idea: work with
\begin{equation}
  B \defeq A - \lambda_1\frac{\vec{x}_1\vec{x}_1^\ast}{\vec{x}_1^\ast\vec{x}_1}.
\end{equation}
It has the same eigenpairs as $A$, except that $\lambda_1$ becomes $0$. This works when $A$ is Hermitian.

\begin{proposition}[Hotelling Deflation]
  \label{prop:hotelling}
  Let $A \in \K^{m \times m}$ be Hermitian with eigenpairs $(\lambda_i, \vec{x}_i)$, where the $\vec{x}_i$ are pairwise orthogonal. Then $B\vec{x}_1 = \zerovec$ and $B\vec{x}_i = \lambda_i\vec{x}_i$ for $i = 2, \dots, m$.
\end{proposition}

\begin{proof}
  For $i = 1$: $B\vec{x}_1 = \lambda_1\vec{x}_1 - \lambda_1\vec{x}_1\dfrac{\vec{x}_1^\ast\vec{x}_1}{\vec{x}_1^\ast\vec{x}_1} = \zerovec$.

  For $i \ge 2$: $\vec{x}_1^\ast\vec{x}_i = 0$, so the correction term vanishes, and $B\vec{x}_i = A\vec{x}_i = \lambda_i\vec{x}_i$.
\end{proof}

Power iteration on $B$ now converges to the eigenpair with the next largest modulus. Repeating this gives all eigenpairs, one by one.

Two remarks.
\begin{itemize}
  \item The proof needs orthogonal eigenvectors. Hermitian $A$ has them (\Cref{prop:herm-orth}). For non-Hermitian $A$, $\vec{x}_1^\ast\vec{x}_i \ne 0$ in general, and the other eigenpairs change.
  \item We never form $B$; if $A$ is sparse, $B$ is dense. We compute $B\vec{z} = A\vec{z} - \lambda_1\vec{x}_1(\vec{x}_1^\ast\vec{z})/(\vec{x}_1^\ast\vec{x}_1)$, at the cost of one product with $A$ plus $O(m)$.
\end{itemize}

\section{Subspace Iteration: Motivation}
\label{sec:subspace-motivation}

So far we can compute single eigenpairs. With deflation we can, in principle, compute them all one by one. The problem is speed.
\begin{itemize}
  \item $N$ eigenpairs need at least $N$ matrix-vector products (in practice many more).
  \item These products happen \emph{serially}: we cannot start eigenpair $k + 1$ before eigenpair $k$ is done.
  \item Each product loads all of $A$ from RAM to do only $2m^2$ flops. Its intensity is $q \approx 2$ (\Cref{sec:intensity}). Memory bandwidth limits it.
\end{itemize}
So we load the matrix from RAM at least $N$ times.

The alternative: run power iteration on \emph{many vectors at the same time}. For $Z \in \K^{m \times n}$, the product $AZ$ does $2m^2n$ flops but reads $A$ once. Matrix-vector products become matrix-matrix products, which run near peak speed (\Cref{ch:performance}). This is \emph{subspace iteration}.

We must keep the columns independent. Otherwise every column converges to $\vec{x}_1$. So we orthonormalize them after each step, for example by a QR factorization (\Cref{ch:orth-iter}).

What should such an iteration converge to? To answer this, we first describe all eigenpairs as one matrix factorization.

\section{Eigenvalue Problems as Matrix Factorizations}
\label{sec:eig-factorization}

\begin{proposition}[Distinct Eigenvalues Give an Eigenvalue Decomposition]
  \label{prop:distinct-diag}
  If $A \in \K^{m \times m}$ has $m$ distinct eigenvalues $\lambda_1, \dots, \lambda_m$ with eigenvectors $\vec{x}_1, \dots, \vec{x}_m$, then
  \begin{equation}
    A = X\Lambda X^{-1}, \qquad X = \begin{bmatrix} \vec{x}_1 & \cdots & \vec{x}_m \end{bmatrix}, \quad \Lambda = \diag(\lambda_1, \dots, \lambda_m).
  \end{equation}
\end{proposition}

\begin{proof}
  Column $i$ of $AX$ is $A\vec{x}_i$. Column $i$ of $X\Lambda$ is $\lambda_i\vec{x}_i$. So the $m$ equations $A\vec{x}_i = \lambda_i\vec{x}_i$ say $AX = X\Lambda$. Eigenvectors for distinct eigenvalues are linearly independent (\Cref{lem:distinct-indep}). So $X$ is invertible, and $A = X\Lambda X^{-1}$.
\end{proof}

So computing all eigenpairs means computing the factorization $A = X\Lambda X^{-1}$.

For self-adjoint matrices ($A^\ast = A$, i.e., Hermitian), we can do better: $X$ can be chosen orthogonal.

\begin{theorem}[Spectral Theorem]
  \label{thm:spectral}
  If $A \in \K^{m \times m}$ is self-adjoint, there is a unitary $X$ with
  \begin{equation}
    A = X\Lambda X^\ast,
  \end{equation}
  and $\Lambda$ is real~\cite[Thm.~24.7]{TB}, \cite[7.29, 7.31]{Axler}.
\end{theorem}

Then $X^{-1} = X^\ast$ is free, and $\kappa_2(X) = 1$: changing to eigenvector coordinates does not amplify errors. The proof follows from the Schur factorization (\Cref{cor:spectral}).

\section{Defective Matrices and Invariant Subspaces}
\label{sec:defective}

Are all matrices diagonalizable? No. Consider
\begin{equation}
  J = \begin{bmatrix} \lambda & 1 \\ 0 & \lambda \end{bmatrix}.
\end{equation}
What are its eigenpairs?
\begin{itemize}
  \item $J$ is triangular, so its only eigenvalue is $\lambda$.
  \item $(J - \lambda I)\vec{x} = \left[\begin{smallmatrix} 0 & 1 \\ 0 & 0 \end{smallmatrix}\right]\vec{x} = (x_2, 0)^\T$. This is zero only if $x_2 = 0$.
\end{itemize}
So $(\lambda, \vec{e}_1)$ is the only eigenpair, up to scaling. We need two independent eigenvectors to build $X$, but we have only one. Such matrices are called \emph{defective}. (For the precise definition via algebraic and geometric multiplicity, see \Cref{sec:multiplicity}.)

To see what happens, take $\lambda = 0$: $N = \left[\begin{smallmatrix} 0 & 1 \\ 0 & 0 \end{smallmatrix}\right]$. Then $N\vec{e}_2 = \vec{e}_1$ and $N\vec{e}_1 = \zerovec$. So $N$ pushes $\vec{e}_2$ to $\vec{e}_1$, and $\vec{e}_1$ to $\zerovec$. Only $\vec{e}_1$ is mapped to a multiple of itself.

\paragraph{Intuition.} Still, all vectors show ``$\lambda$-growth'' under $J$. For example, $J\vec{e}_2 = \lambda\vec{e}_2 + \vec{e}_1$. It is not a multiple of $\vec{e}_2$, but it stays in $\spn(\vec{e}_1, \vec{e}_2)$, and the diagonal of $J$ is still $\lambda$. (Concretely, $J^k = \left[\begin{smallmatrix} \lambda^k & k\lambda^{k-1} \\ 0 & \lambda^k \end{smallmatrix}\right]$ grows like $\abs{\lambda}^k$, up to a factor $k$.)

\paragraph{Idea.} Generalize the $\lambda$-eigenspace to an \emph{invariant subspace with $\lambda$-growth}: a subspace that $A$ maps into itself. On an eigenspace, $A$ acts as $\lambda I$. On an invariant subspace, $A$ may act as any matrix $B$.

\begin{definition}[Invariant Subspace]
  \label{def:invariant}
  Let $X = [\vec{x}_1\ \cdots\ \vec{x}_n] \in \K^{m \times n}$ have linearly independent columns. The space $\range(X)$ spanned by its columns is \emph{$A$-invariant} if and only if there is $B \in \K^{n \times n}$ with
  \begin{equation}
    AX = XB.
  \end{equation}
\end{definition}

How to read it:
\begin{itemize}
  \item Column $j$ says $A\vec{x}_j = X\vec{b}_j$. So $A$ maps every basis vector back into $\range(X)$. Equivalently, $A\,\range(X) \subseteq \range(X)$.
  \item $B$ is the matrix of $A$ on this subspace, in the basis $X$.
  \item Special cases: an eigenpair ($n = 1$, $B = \lambda$); a diagonalizable $A$ ($X$ all eigenvectors, $B = \Lambda$); the matrix $J$ ($X = I$, $B = J$).
\end{itemize}

\begin{proposition}[Eigenvalues on an Invariant Subspace]
  \label{prop:invariant-eig}
  Let $AX = XB$ with $X$ of full column rank. Then every eigenvalue of $B$ is an eigenvalue of $A$. If the columns of $X = Q$ are orthonormal, then $B = Q^\ast AQ$~\cite[Prop.~4.3]{Demmel}.
\end{proposition}

\begin{proof}
  If $B\vec{v} = \lambda\vec{v}$ with $\vec{v} \ne \zerovec$, then $A(X\vec{v}) = XB\vec{v} = \lambda X\vec{v}$, and $X\vec{v} \ne \zerovec$. If $Q^\ast Q = I$, multiply $AQ = QB$ by $Q^\ast$ on the left.
\end{proof}

\section{The Jordan Normal Form}
\label{sec:jordan}

If we split the whole space into invariant subspaces of this kind, we get the Jordan normal form.

\begin{theorem}[Jordan Normal Form]
  \label{thm:jordan}
  For every $A \in \K^{m \times m}$ there is a nonsingular $S \in \C^{m \times m}$ with
  \begin{equation}
    A = SJS^{-1}, \qquad J = \begin{bmatrix} J_1 & & \\ & \ddots & \\ & & J_k \end{bmatrix}, \qquad J_\ell = \begin{bmatrix} \lambda_\ell & 1 & & \\ & \lambda_\ell & \ddots & \\ & & \ddots & 1 \\ & & & \lambda_\ell \end{bmatrix} \in \C^{n_\ell \times n_\ell}.
  \end{equation}
  $J$ is unique up to the order of the blocks~\cite[Thm.~4.1]{Demmel}, \cite[8.46]{Axler}.
\end{theorem}

The Jordan form decomposes the space into $A$-invariant subspaces. Split $S = [S_1\ \cdots\ S_k]$ to match the blocks. Then $AS_\ell = S_\ell J_\ell$: each block is an invariant subspace with $B = J_\ell$. $A$ is diagonalizable exactly when all blocks are $1 \times 1$.

\begin{proposition}[One Eigenvector per Jordan Block]
  \label{prop:jordan-block}
  Every Jordan block $J_\ell$ has, up to scaling, only one eigenvector, $\vec{e}_1$~\cite[Prop.~4.2]{Demmel}.
\end{proposition}

\begin{proof}
  $J_\ell - \lambda_\ell I$ shifts the entries up: $(J_\ell - \lambda_\ell I)\vec{x} = (x_2, \dots, x_{n_\ell}, 0)^\T$. This is zero only if $\vec{x} \in \spn(\vec{e}_1)$.
\end{proof}

\paragraph{Problem.} The Jordan form is not (numerically) stable, for two reasons.

\emph{First, it is discontinuous in $A$.}

\begin{example}[A Tiny Perturbation Changes the Jordan Form]
  \label{ex:jordan-unstable}
  Perturb $N = \left[\begin{smallmatrix} 0 & 1 \\ 0 & 0 \end{smallmatrix}\right]$ to $A_\eps = \left[\begin{smallmatrix} \eps & 1 \\ 0 & 2\eps \end{smallmatrix}\right]$, $\eps > 0$. Its eigenvalues $\eps, 2\eps$ are distinct, with eigenvectors $\vec{e}_1$ and $(1, \eps)^\T$. So
  \begin{equation}
    A_\eps = S_\eps\begin{bmatrix} \eps & 0 \\ 0 & 2\eps \end{bmatrix}S_\eps^{-1}, \qquad S_\eps = \begin{bmatrix} 1 & 1 \\ 0 & \eps \end{bmatrix}.
  \end{equation}
  As $\eps \to 0$, $A_\eps \to N$, but its Jordan form $\diag(\eps, 2\eps) \to 0 \ne N$.
\end{example}

In floating point, perturbations of size $\epsm\norm{A}$ are always present. So no computation can decide whether $A$ has a nontrivial Jordan block.

\emph{Second, $S$ can be arbitrarily ill-conditioned.} The columns of $S_\eps$ are nearly parallel, and $\kappa_2(S_\eps) \approx 2/\eps$; no rescaling of the columns helps (\Cref{sec:jordan-scaling}). Even if we computed $J$ with only a tiny error $\delta J$, the backward error $\delta A = S\,\delta J\,S^{-1}$ satisfies
\begin{equation}
  \norm{\delta A} \le \kappa(S)\norm{\delta J},
\end{equation}
which can be much larger than $\epsm\norm{A}$. So the Jordan form cannot be computed in a backward stable way~\cite[Example~4.3]{Demmel}.

So we should only use \emph{unitary} similarity transformations, with $\kappa_2 = 1$. We cannot reach a form as simple as $J$ that way. But we get something almost as good.

\section{The Schur Factorization}
\label{sec:schur-fact}

\begin{theorem}[Schur Factorization]
  \label{thm:schur}
  For every $A \in \K^{m \times m}$ there exist a unitary $Q$ and an upper triangular $T$ with
  \begin{equation}
    A = QTQ^\ast.
  \end{equation}
  The eigenvalues of $A$ are the diagonal entries of $T$~\cite[Thm.~24.9]{TB}, \cite[Thm.~4.2]{Demmel}, \cite[6.38]{Axler}.
\end{theorem}

Compared with the other two factorizations:
\begin{itemize}
  \item unlike $X\Lambda X^{-1}$, it exists for \emph{every} matrix, defective or not;
  \item unlike $SJS^{-1}$, it uses a unitary $Q$, so it is stable;
  \item the price: $T$ is only triangular, not diagonal.
\end{itemize}

\begin{proof}
  We use the fact that every matrix has at least one eigenvalue. Induction on $m$; for $m = 1$ take $Q = [1]$.

  Let $(\lambda, \vec{u})$ be an eigenpair with $\norm{\vec{u}} = 1$. Extend $\vec{u}$ to a square unitary $U = [\vec{u}\ \tilde{U}]$. Then
  \begin{equation}
    U^\ast AU = \begin{bmatrix} \vec{u}^\ast A\vec{u} & \vec{u}^\ast A\tilde{U} \\ \tilde{U}^\ast A\vec{u} & \tilde{U}^\ast A\tilde{U} \end{bmatrix} = \begin{bmatrix} \lambda & \vec{u}^\ast A\tilde{U} \\ \zerovec & \tilde{U}^\ast A\tilde{U} \end{bmatrix},
  \end{equation}
  since $A\vec{u} = \lambda\vec{u}$, $\vec{u}^\ast\vec{u} = 1$ and $\tilde{U}^\ast\vec{u} = \zerovec$.

  Then recurse on the bottom right part. By induction, $\tilde{U}^\ast A\tilde{U} = \tilde{Q}\tilde{T}\tilde{Q}^\ast$. With $Q \defeq U\diag(1, \tilde{Q})$,
  \begin{equation}
    Q^\ast AQ = \begin{bmatrix} \lambda & \vec{u}^\ast A\tilde{U}\tilde{Q} \\ \zerovec & \tilde{T} \end{bmatrix}
  \end{equation}
  is upper triangular. We call it $T$. $A$ and $T$ are similar, so they have the same eigenvalues: the diagonal of $T$.
\end{proof}

The first step uses the fundamental theorem of algebra, which is where $\C$ enters. A real matrix may have no real eigenvalue (a rotation of the plane). So $Q$ and $T$ are complex in general, even for real $A$.

For Hermitian $A$, the spectral theorem now follows in two lines.

\begin{corollary}[Normal Matrices and the Spectral Theorem]
  \label{cor:spectral}
  If $A$ is normal ($A^\ast A = AA^\ast$), then the triangular factor $T$ of any Schur factorization of $A$ is diagonal, so $A = Q\Lambda Q^\ast$. If $A$ is Hermitian, $\Lambda$ is also real. In particular, \Cref{thm:spectral} holds~\cite[Thm.~24.8]{TB}.
\end{corollary}

\begin{proof}
  \emph{Hermitian case.} $T^\ast = Q^\ast A^\ast Q = Q^\ast AQ = T$. A Hermitian upper triangular matrix is diagonal, with real diagonal.

  \emph{Normal case.} See \Cref{thm:normal-diag} in \Cref{ch:orth-iter}.
\end{proof}

\subsection{The Real Schur Form}

When we work with real matrices, we prefer to stay with real numbers. Complex arithmetic costs more, and rounding would break the exact conjugate symmetry of the eigenvalues.

\begin{theorem}[Real Schur Form]
  \label{thm:real-schur}
  If $A \in \R^{m \times m}$, there exist an orthogonal $Q$ and a block upper triangular $T$ with $1 \times 1$ and $2 \times 2$ diagonal blocks such that
  \begin{equation}
    A = QTQ^\T.
  \end{equation}
  The $1 \times 1$ blocks are the real eigenvalues of $A$. Each $2 \times 2$ block holds a pair of complex conjugate eigenvalues~\cite[Thm.~4.3]{Demmel}.
\end{theorem}

\paragraph{Key idea.} The non-real eigenvalues of a real matrix appear in complex conjugate pairs. Each pair gives a \emph{real} two-dimensional invariant subspace:

\begin{lemma}[A Conjugate Pair Gives a Real Invariant Plane]
  \label{lem:conj-pair}
  Let $A \in \R^{m \times m}$ and $A\vec{x} = \lambda\vec{x}$ with $\lambda = \alpha + i\beta$, $\beta \ne 0$, $\vec{x} = \vec{a} + i\vec{b}$ ($\vec{a}, \vec{b}$ real). Then $\vec{a}, \vec{b}$ are linearly independent and
  \begin{equation}
    A\begin{bmatrix} \vec{a} & \vec{b} \end{bmatrix} = \begin{bmatrix} \vec{a} & \vec{b} \end{bmatrix}\begin{bmatrix} \alpha & \beta \\ -\beta & \alpha \end{bmatrix}.
  \end{equation}
  The $2 \times 2$ matrix has eigenvalues $\alpha \pm i\beta$.
\end{lemma}

\begin{proof}
  Take real and imaginary parts of $A(\vec{a} + i\vec{b}) = (\alpha + i\beta)(\vec{a} + i\vec{b})$: $A\vec{a} = \alpha\vec{a} - \beta\vec{b}$ and $A\vec{b} = \beta\vec{a} + \alpha\vec{b}$. If $\vec{a}, \vec{b}$ were dependent, $\vec{x}$ would be a complex multiple of a real vector $\vec{r}$, and $A\vec{r} = \lambda\vec{r}$ would force $\lambda$ to be real.
\end{proof}

\begin{proof}[Proof of \Cref{thm:real-schur}]
  Same induction as for \Cref{thm:schur}, in real arithmetic. A real eigenvalue gives a $1 \times 1$ block as before. Otherwise, orthonormalize $[\vec{a}\ \vec{b}]$ from \Cref{lem:conj-pair} to $\hat{Q} \in \R^{m \times 2}$. Its span is invariant, so $A\hat{Q} = \hat{Q}\hat{B}$ with $\hat{B} = \hat{Q}^\T A\hat{Q}$ (\Cref{prop:invariant-eig}). Extend to an orthogonal $U = [\hat{Q}\ \tilde{Q}]$. Then $\tilde{Q}^\T A\hat{Q} = \tilde{Q}^\T\hat{Q}\hat{B} = 0$, so
  \begin{equation}
    U^\T AU = \begin{bmatrix} \hat{B} & \hat{Q}^\T A\tilde{Q} \\ 0 & \tilde{Q}^\T A\tilde{Q} \end{bmatrix},
  \end{equation}
  and we recurse on $\tilde{Q}^\T A\tilde{Q}$.
\end{proof}

\section{Computing Eigenvectors from the Schur Form}
\label{sec:schur-eigvec}

The Schur factorization gives the eigenvalues. What about the eigenvectors? With $A = QTQ^\ast$,
\begin{equation}
  T\vec{x} = \lambda\vec{x} \iff (QTQ^\ast)(Q\vec{x}) = \lambda Q\vec{x}.
\end{equation}
So we need the eigenvectors of the triangular matrix $T$, and then multiply by $Q$.

Let $\lambda = t_{kk}$ be a simple eigenvalue. Partition $T - \lambda I$ around row and column $k$, and solve $(T - \lambda I)\vec{x} = \zerovec$:
\begin{equation}
  \zerovec = \begin{bmatrix} T_{11} - \lambda I & \vec{t}_{12} & T_{13} \\ & 0 & \vec{t}_{23}^\ast \\ & & T_{33} - \lambda I \end{bmatrix}\begin{bmatrix} \vec{x}_1 \\ x_2 \\ \vec{x}_3 \end{bmatrix} = \begin{bmatrix} (T_{11} - \lambda I)\vec{x}_1 + \vec{t}_{12}x_2 + T_{13}\vec{x}_3 \\ \vec{t}_{23}^\ast\vec{x}_3 \\ (T_{33} - \lambda I)\vec{x}_3 \end{bmatrix}.
\end{equation}
Since $\lambda$ is simple, $T_{11} - \lambda I$ and $T_{33} - \lambda I$ are nonsingular. We solve from the bottom up:
\begin{itemize}
  \item the third row gives $\vec{x}_3 = \zerovec$, and then the second row holds;
  \item $x_2$ is free; we choose $x_2 = 1$;
  \item the first row gives $\vec{x}_1 = (\lambda I - T_{11})^{-1}\vec{t}_{12}$.
\end{itemize}

\begin{proposition}[Eigenvectors of a Triangular Matrix]
  \label{prop:triangular-eigvec}
  For a simple eigenvalue $\lambda = t_{kk}$ of the upper triangular $T$,
  \begin{equation}
    \vec{x} = \begin{bmatrix} (\lambda I - T_{11})^{-1}\vec{t}_{12} \\ 1 \\ \zerovec \end{bmatrix}
  \end{equation}
  is an eigenvector of $T$, and $Q\vec{x}$ is an eigenvector of $A$~\cite[\S4.2.1]{Demmel}.
\end{proposition}

\paragraph{Cost.} One triangular solve of size $k - 1$, about $(k-1)^2$ flops, plus $2mk$ flops for $Q\vec{x}$. For all $k$, this is $O(m^3)$, the same order as the Schur form itself. For $k = 1$, $\vec{x} = \vec{e}_1$: the first Schur vector $\vec{q}_1$ is always an eigenvector.

\paragraph{Caveats.}
\begin{itemize}
  \item If $\lambda$ is repeated on the diagonal of $T_{11}$, then $T_{11} - \lambda I$ is singular. This is the defective case again.
  \item If $\lambda$ is close to another diagonal entry of $T_{11}$, then $(\lambda I - T_{11})^{-1}$ is large and $\vec{x}$ is sensitive. This is not a flaw of the method: the eigenvector itself is ill-conditioned.
\end{itemize}

\subsection{Eigenvectors for Distinct Eigenvalues Are Independent}

\begin{lemma}[Eigenvectors for Distinct Eigenvalues]
  \label{lem:distinct-indep}
  Eigenvectors $\vec{x}_1, \dots, \vec{x}_k$ of $A$ corresponding to distinct eigenvalues $\lambda_1, \dots, \lambda_k$ are linearly independent~\cite[5.11]{Axler}.
\end{lemma}

\begin{proof}
  Suppose not. Among all vanishing combinations with nonzero coefficients, pick one with the fewest terms: $\sum_{i \in S}c_i\vec{x}_i = \zerovec$, all $c_i \ne 0$. Then $S$ has at least two elements, since eigenvectors are nonzero. Fix $j \in S$ and apply $A - \lambda_jI$:
  \begin{equation}
    \sum_{i \in S \setminus \{j\}}c_i(\lambda_i - \lambda_j)\vec{x}_i = \zerovec.
  \end{equation}
  The term $i = j$ dropped out. All remaining coefficients are nonzero, since $\lambda_i \ne \lambda_j$. This is a shorter vanishing combination, a contradiction.
\end{proof}

\subsection{Algebraic and Geometric Multiplicity}
\label{sec:multiplicity}

This subsection follows~\cite[Lecture~24]{TB}. Throughout, $A \in \C^{m \times m}$.

\begin{itemize}
  \item The \emph{eigenspace} $E_\lambda = \nullsp(A - \lambda I)$ is an invariant subspace. Its dimension is the \emph{geometric multiplicity} of $\lambda$: the largest number of independent eigenvectors for $\lambda$.
  \item The \emph{characteristic polynomial} $p_A(z) = \det(zI - A)$ is monic of degree $m$. $\lambda$ is an eigenvalue if and only if $\lambda I - A$ is singular, i.e., $p_A(\lambda) = 0$. So a real matrix may have complex eigenvalues.
  \item By the fundamental theorem of algebra, $p_A(z) = (z - \lambda_1)\cdots(z - \lambda_m)$. The multiplicity of $\lambda$ as a root is its \emph{algebraic multiplicity}. So $A$ has $m$ eigenvalues, counted with algebraic multiplicity.
  \item Similar matrices $A$ and $X^{-1}AX$ have the same characteristic polynomial, since $\det(zI - X^{-1}AX) = \det(X^{-1})\det(zI - A)\det(X)$. They also have the same geometric multiplicities, since $X^{-1}$ maps $E_\lambda(A)$ onto $E_\lambda(X^{-1}AX)$.
\end{itemize}

\begin{definition}[Defective]
  \label{def:multiplicity}
  An eigenvalue whose algebraic multiplicity exceeds its geometric multiplicity is \emph{defective}. A matrix with a defective eigenvalue is a \emph{defective matrix}.
\end{definition}

Example~\cite[Ex.~24.1]{TB}: $2I_3$ and $\left[\begin{smallmatrix} 2 & 1 & \\ & 2 & 1 \\ & & 2 \end{smallmatrix}\right]$ both have $p(z) = (z - 2)^3$. The first has three independent eigenvectors; the second only $\vec{e}_1$, so it is defective.

\begin{theorem}[{\cite[Thm.~24.4]{TB}}]
  \label{thm:alg-geq-geo}
  The algebraic multiplicity of an eigenvalue is at least its geometric multiplicity.
\end{theorem}

\begin{proof}
  Let $n = \dim E_\lambda$, and let $\hat{V}$ hold an orthonormal basis of $E_\lambda$. Extend to a unitary $V = [\hat{V}\ \tilde{V}]$. Since $A\hat{V} = \lambda\hat{V}$,
  \begin{equation}
    V^\ast AV = \begin{bmatrix} \lambda I_n & C \\ 0 & D \end{bmatrix}, \qquad \det(zI - V^\ast AV) = (z - \lambda)^n\det(zI - D).
  \end{equation}
  So $\lambda$ is a root of $p_A$ of multiplicity at least $n$.
\end{proof}

\begin{theorem}[{\cite[Thm.~24.5]{TB}}]
  \label{thm:nondefective}
  $A$ has an eigenvalue decomposition $A = X\Lambda X^{-1}$ if and only if $A$ is nondefective.
\end{theorem}

\begin{proof}
  ($\Rightarrow$) $A$ is similar to $\Lambda$, so it has the same multiplicities, and a diagonal matrix is nondefective.

  ($\Leftarrow$) Take a basis of each eigenspace. Their sizes add up to the algebraic multiplicities, so to $m$. Together they are independent: group a vanishing combination by eigenvalue as $\vec{u}_1 + \dots + \vec{u}_r = \zerovec$ with $\vec{u}_s \in E_{\mu_s}$; by \Cref{lem:distinct-indep} every $\vec{u}_s = \zerovec$, so all coefficients vanish. These $m$ vectors form an invertible $X$ with $AX = X\Lambda$.
\end{proof}

Another word for nondefective is \emph{diagonalizable}.

\subsection{Powers on an Invariant Subspace}

From $AX = XB$ we get $A^kX = XB^k$. So on an invariant subspace, powers of $A$ (and power iteration) behave like powers of $B$. For the $2 \times 2$ block, $J = \lambda I + N$ with $N^2 = 0$, and the binomial formula gives $J^k = \lambda^kI + k\lambda^{k-1}N$. Even for $\abs{\lambda} < 1$, $\norm{J^k}$ can first grow before it decays (see the supplement of \Cref{ch:eigen}).

\subsection{No Column Scaling Makes $S_\eps$ Well-Conditioned}
\label{sec:jordan-scaling}

Normalize the columns of $S_\eps$ to unit vectors $\vec{u}, \vec{v}$ with angle $\theta$, $\tan\theta = \eps$. Then $\kappa_2 = \cot(\theta/2) \approx 2/\eps$. For any scaling $SD = [a\vec{u}\ b\vec{v}]$:
\begin{itemize}
  \item with $\vec{w} = (1/a, -1/b)^\T$ we get $SD\vec{w} = \vec{u} - \vec{v}$ and $\norm{\vec{w}} \ge 1/\min(\abs{a}, \abs{b})$, so
  \begin{equation*}
    \sigma_{\min}(SD) \le \min(\abs{a}, \abs{b})\norm{\vec{u} - \vec{v}};
  \end{equation*}
  \item $\sigma_{\max}(SD) \ge \max(\abs{a}, \abs{b})$.
\end{itemize}
Hence $\kappa_2(SD) \ge 1/\norm{\vec{u} - \vec{v}} = 1/(2\sin(\theta/2)) \approx 1/\eps$. Since $A_\eps$ is diagonalizable, this also shows that eigenvector matrices of matrices close to defective ones are badly conditioned.

\subsection{Schur versus Jordan}

Both forms exist for every matrix. Jordan uses an $S$ that may be ill-conditioned, and it is discontinuous. Schur uses a unitary $Q$ with $\kappa_2(Q) = 1$. The price is that $T$ is only triangular: its strictly upper part may be dense.

\subsection{Nested Invariant Subspaces}

We write $AQ = QT$ and keep the first $k$ columns. Since $T$ is upper triangular, this gives $AQ_{:,1:k} = Q_{:,1:k}T_{1:k,1:k}$. So $\spn(\vec{q}_1) \subset \spn(\vec{q}_1, \vec{q}_2) \subset \cdots$ is a nested sequence of invariant subspaces (\Cref{def:invariant}), with orthonormal bases. Conversely, if all leading spans of a basis are invariant, the basis gives an upper triangular matrix~\cite[5.39]{Axler}. This is the goal of subspace iteration with orthonormalization (\Cref{sec:subspace-motivation}).

\subsection{How Ill-Conditioned Eigenvalues Near a Jordan Block Are}

In \Cref{ex:jordan-unstable}, the eigenvalues moved by only $O(\eps)$, while the Jordan structure and $S$ broke down. A different perturbation moves the eigenvalues themselves much more. Put $\eps$ in the bottom left corner of an $n \times n$ Jordan block with eigenvalue $0$. The result is the companion matrix (\Cref{lem:companion}) of $z^n - \eps$. Its eigenvalues are the $n$ complex $n$-th roots of $\eps$, all of modulus $\eps^{1/n}$~\cite[Example~4.4]{Demmel}. For $n = 10$ and $\eps = 10^{-10}$, a perturbation of size $10^{-10}$ moves the eigenvalues by $0.1$. A multiple eigenvalue in a nontrivial Jordan block has infinite condition number.

\subsection{The Bauer--Fike Theorem}

We can make the role of $\kappa(X)$ quantitative. Let $A = X\Lambda X^{-1}$ be diagonalizable, and let $\mu$ be an eigenvalue of $A + E$. Then
\begin{equation}
  \min_i\abs{\mu - \lambda_i} \le \kappa_2(X)\norm{E}_2.
\end{equation}
To see this, assume $\mu$ is not an eigenvalue of $A$. Since $A + E - \mu I$ is singular, so is $X^{-1}(A + E - \mu I)X = (\Lambda - \mu I) + X^{-1}EX$. Hence $I + (\Lambda - \mu I)^{-1}X^{-1}EX$ is also singular. A matrix $I + M$ can only be singular if $\norm{M} \ge 1$. So
\begin{equation}
  1 \le \norm{(\Lambda - \mu I)^{-1}}\,\norm{X^{-1}}\,\norm{E}\,\norm{X} = \frac{\kappa_2(X)\norm{E}_2}{\min_i\abs{\lambda_i - \mu}}.
\end{equation}
For normal matrices, $X$ can be unitary. Then $\kappa_2(X) = 1$, and the eigenvalues move by at most $\norm{E}_2$. When $A$ approaches a defective matrix, $\kappa_2(X) \to \infty$ and the bound becomes useless. This agrees with the $\eps^{1/n}$ behavior above. See~\cite[\S4.3]{Demmel}.
