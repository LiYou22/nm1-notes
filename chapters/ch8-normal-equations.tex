\section{Recap and Motivation}

Last lecture we finished the QR factorization.
\begin{itemize}
  \item \emph{Using $Q$.} Householder QR never forms $Q$. To apply $Q^\ast$ to a vector, we apply the stored reflectors in the order $\vec{v}_1, \dots, \vec{v}_n$. To apply $Q$, we use the reverse order.
  \item \emph{Givens rotations.} A rotation in the $(i, j)$ plane with $c = A_{ii}/\sqrt{A_{ii}^2 + A_{ji}^2}$ and $s = A_{ji}/\sqrt{A_{ii}^2 + A_{ji}^2}$ sets one entry to zero. Repeating this gives Givens QR.
  \item \emph{Full and reduced QR}, and the \emph{existence and uniqueness} of QR.
\end{itemize}

\paragraph{Solving overdetermined least squares.} We now come back to the problem that led us to QR: given $A \in \K^{m \times n}$ with $m > n$ and $\vec{b} \in \K^m$, find the $\vec{x}$ that minimizes
\begin{equation}
  \norm{A\vec{x} - \vec{b}}^2.
\end{equation}
There are more equations than unknowns, so $A\vec{x} = \vec{b}$ usually has no solution. We cannot solve it as in the square case.

We already saw an informal reason why $\vec{x} = \hat{R}^{-1}\hat{Q}^\ast\vec{b}$ solves this problem, for a reduced QR factorization $A = \hat{Q}\hat{R}$. Let us recall it. We extend $\vec{q}_1, \dots, \vec{q}_n$ to an orthonormal basis $\vec{q}_1, \dots, \vec{q}_m$ of $\K^m$. In this basis,
\begin{itemize}
  \item $\vec{b}$ has the coordinates $Q^\ast\vec{b}$;
  \item $A\vec{x} = \hat{Q}(\hat{R}\vec{x})$ has the coordinates $\hat{R}\vec{x}$ in the first $n$ directions, and $0$ in the other $m - n$.
\end{itemize}
Since $\hat{R}$ is invertible, we can make the first $n$ coordinates of $A\vec{x}$ equal to those of $\vec{b}$, by solving $\hat{R}\vec{x} = \hat{Q}^\ast\vec{b}$. The other $m - n$ coordinates of $A\vec{x}$ are always $0$, so we cannot reduce the error there. For $m = 3$ and $n = 2$, we get the following picture.

\small In the basis $\vec{q}_1, \vec{q}_2, \vec{q}_3$, $A\vec{x}$ can match the first two coordinates of $\vec{b}$. The third coordinate, $(Q^\ast\vec{b})_3$, is the error that no $\vec{x}$ can remove.

This argument is convincing, but it relies on the picture. Why is matching the coordinates the best choice? Is it the only best choice? \emph{How do we prove this?} One way uses that $Q^\ast$ preserves norms (\Cref{sec:unitary}). In this lecture we take a different way, which needs no factorization at all.

First we answer a more basic question: \emph{what condition does a minimizer satisfy?} Such a condition helps in two ways.
\begin{itemize}
  \item It lets us \emph{check} that the $\vec{x}$ from QR really is a minimizer.
  \item It turns a minimization problem into a \emph{system of equations}.
\end{itemize}
The main result of this lecture is
\begin{equation}
  \vec{x} \text{ minimizes } \norm{A\vec{x} - \vec{b}}^2 \quad\iff\quad A\vec{x} - \vec{b} \perp \range(A) \quad\iff\quad A^\ast A\vec{x} = A^\ast\vec{b}.
\end{equation}
In \Cref{ch:ls} we saw this geometrically; now we prove it. Then we study the matrix $A^\ast A$ of the last system. This leads to Gram matrices and positive semidefinite matrices.

\section{Conventions}
\label{sec:normal-conventions}

We use the inner product $\ip{\vec{x}}{\vec{y}} = \vec{x}^\ast\vec{y}$, as in \Cref{ch:ls,ch:qr}. It is linear in the second argument and conjugate linear in the first. Swapping the two arguments conjugates it: $\ip{\vec{y}}{\vec{x}} = \overline{\ip{\vec{x}}{\vec{y}}}$. So
\begin{equation}
  \ip{\vec{x}}{\vec{y}} + \ip{\vec{y}}{\vec{x}} = 2\operatorname{Re}\ip{\vec{x}}{\vec{y}}.
\end{equation}
We write $\vec{r} \defeq A\vec{x} - \vec{b}$ for the residual, and $\vec{d}$ for a perturbation direction.

We will use the following identity many times in this lecture.

\begin{lemma}[Moving a Matrix Across the Inner Product]
  \label{lem:adjoint}
  For any $M \in \K^{m \times n}$ (not necessarily square or unitary), $\vec{u} \in \K^n$, and $\vec{v} \in \K^m$,
  \begin{equation}
    \ip{M\vec{u}}{\vec{v}} = \ip{\vec{u}}{M^\ast\vec{v}}.
  \end{equation}
\end{lemma}

\begin{proof}
  This follows from associativity: $\ip{M\vec{u}}{\vec{v}} = (M\vec{u})^\ast\vec{v} = \vec{u}^\ast(M^\ast\vec{v}) = \ip{\vec{u}}{M^\ast\vec{v}}$.
\end{proof}

In words: we can move a matrix from one side of the inner product to the other, if we replace $M$ by $M^\ast$. Two remarks.
\begin{itemize}
  \item This is \emph{not} the same as multiplying both sides by $M^\ast$. For example, the $m \times n$ factor $\hat{Q}$ of a reduced QR factorization has $\hat{Q}^\ast\hat{Q} = I$ but $\hat{Q}\hat{Q}^\ast \ne I$. In general $\ip{\hat{Q}^\ast\vec{y}}{\hat{Q}^\ast\vec{z}} \ne \ip{\vec{y}}{\vec{z}}$ (compare \Cref{sec:unitary}).
  \item In Axler's \emph{Linear Algebra Done Right} (Section 7.A), \Cref{lem:adjoint} is used as the definition of the adjoint.
\end{itemize}

\section{The Optimality Condition}

We want to find $\vec{x}$ that minimizes $\norm{A\vec{x} - \vec{b}}^2$. The idea: if $\vec{x}$ is a minimizer, moving it cannot make the value smaller. So for every $\vec{\varepsilon} \in \K^n$,
\begin{equation}
  \norm{A(\vec{x} + \vec{\varepsilon}) - \vec{b}}^2 \ge \norm{A\vec{x} - \vec{b}}^2.
\end{equation}
So we first compute how much $\norm{A\vec{x} - \vec{b}}^2$ changes when we move $\vec{x}$ by $\vec{\varepsilon}$.

\begin{lemma}[How the Squared Residual Changes]
  \label{lem:ls-expand}
  Let $A \in \K^{m \times n}$ and $\vec{b} \in \K^m$. For all $\vec{x}, \vec{\varepsilon} \in \K^n$, with $\vec{r} = A\vec{x} - \vec{b}$,
  \begin{equation}
    \label{eq:ls-expand}
    \norm{A(\vec{x} + \vec{\varepsilon}) - \vec{b}}^2 - \norm{A\vec{x} - \vec{b}}^2 = \norm{A\vec{\varepsilon}}^2 + 2\operatorname{Re}\ip{A\vec{\varepsilon}}{\vec{r}}.
  \end{equation}
\end{lemma}

\begin{proof}
  Since $A(\vec{x} + \vec{\varepsilon}) - \vec{b} = A\vec{\varepsilon} + \vec{r}$, we have
  \begin{equation}
    \begin{aligned}
      \norm{A\vec{\varepsilon} + \vec{r}}^2 - \norm{\vec{r}}^2
      &= \ip{A\vec{\varepsilon} + \vec{r}}{A\vec{\varepsilon} + \vec{r}} - \ip{\vec{r}}{\vec{r}} \\
      &= \ip{A\vec{\varepsilon}}{A\vec{\varepsilon}} + \ip{A\vec{\varepsilon}}{\vec{r}} + \underbrace{\ip{\vec{r}}{A\vec{\varepsilon}}}_{=\,\overline{\ip{A\vec{\varepsilon}}{\vec{r}}}} \\
      &= \norm{A\vec{\varepsilon}}^2 + 2\operatorname{Re}\ip{A\vec{\varepsilon}}{\vec{r}},
    \end{aligned}
  \end{equation}
  In the last step we used $z + \bar{z} = 2\operatorname{Re}z$.
\end{proof}

This holds for any $\vec{x}$. Look at the right-hand side:
\begin{itemize}
  \item The term $\norm{A\vec{\varepsilon}}^2$ is always $\ge 0$, so it never makes the value smaller.
  \item Only the mixed term $2\operatorname{Re}\ip{A\vec{\varepsilon}}{\vec{r}}$ can be negative.
\end{itemize}
So we guess: $\vec{x}$ is a minimizer exactly when the mixed term is zero for every $\vec{\varepsilon}$. The next theorem shows that this is true.

\begin{theorem}[Optimality Condition for Least Squares]
  \label{thm:ls-optimality}
  Let $A \in \K^{m \times n}$ and $\vec{b} \in \K^m$. Then $\vec{x} \in \K^n$ minimizes $\norm{A\vec{x} - \vec{b}}^2$ if and only if the residual is orthogonal to $\range(A)$:
  \begin{equation}
    \label{eq:ls-orth}
    \ip{A\vec{d}}{A\vec{x} - \vec{b}} = 0 \qquad \text{for all } \vec{d} \in \K^n.
  \end{equation}
  Also, if $\vec{x}$ is a minimizer, then the minimizers are exactly the vectors in $\vec{x} + \nullsp(A)$. So the minimizer is unique if and only if $A$ has full column rank.
\end{theorem}

\begin{proof}
  Write $\vec{r} = A\vec{x} - \vec{b}$.

  \emph{If $\vec{x}$ is a minimizer, the residual is orthogonal.} Let $\vec{x}$ be a minimizer. Take any $\vec{d} \in \K^n$ and $\delta > 0$. By \Cref{lem:ls-expand} with $\vec{\varepsilon} = \delta\vec{d}$,
  \begin{equation}
    0 \le \norm{A(\vec{x} + \delta\vec{d}) - \vec{b}}^2 - \norm{A\vec{x} - \vec{b}}^2 = \delta^2\norm{A\vec{d}}^2 + 2\delta\operatorname{Re}\ip{A\vec{d}}{\vec{r}}.
  \end{equation}
  We divide by $\delta$ and let $\delta \to 0^+$:
  \begin{equation*}
    \operatorname{Re}\ip{A\vec{d}}{\vec{r}} \ge 0 \qquad \text{for all } \vec{d} \in \K^n.
  \end{equation*}
  We show that both the real and the imaginary part of $\ip{A\vec{d}}{\vec{r}}$ are zero.

  \emph{Real part.} The inequality holds for every vector in $\K^n$, so it also holds for $-\vec{d}$. The inner product is conjugate-linear in its first argument, and $\overline{-1} = -1$, so
  \begin{equation*}
    0 \le \operatorname{Re}\ip{A(-\vec{d})}{\vec{r}} = \operatorname{Re}\bigl(-\ip{A\vec{d}}{\vec{r}}\bigr) = -\operatorname{Re}\ip{A\vec{d}}{\vec{r}}.
  \end{equation*}
  So $\operatorname{Re}\ip{A\vec{d}}{\vec{r}} \le 0$. Together with $\operatorname{Re}\ip{A\vec{d}}{\vec{r}} \ge 0$ this gives $\operatorname{Re}\ip{A\vec{d}}{\vec{r}} = 0$.

  \emph{Imaginary part.} If $\K = \R$, then $\ip{A\vec{d}}{\vec{r}}$ is real and we are done. If $\K = \C$, we use the vector $i\vec{d}$ instead. The real-part argument above works for every vector, so it gives $\operatorname{Re}\ip{A(i\vec{d})}{\vec{r}} = 0$. Since $\bar{i} = -i$,
  \begin{equation*}
    \ip{A(i\vec{d})}{\vec{r}} = \bar{i}\,\ip{A\vec{d}}{\vec{r}} = -i\ip{A\vec{d}}{\vec{r}}.
  \end{equation*}
  For any complex number $a + bi$ with $a, b$ real, $-i(a + bi) = b - ai$, so $\operatorname{Re}\bigl(-i(a + bi)\bigr) = b$. That is, multiplying by $-i$ turns the imaginary part into the real part. Hence
  \begin{equation*}
    0 = \operatorname{Re}\ip{A(i\vec{d})}{\vec{r}} = \operatorname{Re}\bigl(-i\ip{A\vec{d}}{\vec{r}}\bigr) = \operatorname{Im}\ip{A\vec{d}}{\vec{r}}.
  \end{equation*}

  So $\ip{A\vec{d}}{\vec{r}} = 0$ for all $\vec{d} \in \K^n$.

  \emph{If the residual is orthogonal, $\vec{x}$ is a minimizer.} Suppose \eqref{eq:ls-orth} holds. Take any $\vec{y} \in \K^n$. We use \Cref{lem:ls-expand} with $\vec{\varepsilon} = \vec{y} - \vec{x}$. The mixed term is zero by \eqref{eq:ls-orth}, so
  \begin{equation}
    \label{eq:ls-pythagoras}
    \norm{A\vec{y} - \vec{b}}^2 = \norm{A\vec{x} - \vec{b}}^2 + \norm{A(\vec{y} - \vec{x})}^2 \ge \norm{A\vec{x} - \vec{b}}^2.
  \end{equation}

  \emph{All minimizers.} By \eqref{eq:ls-pythagoras}, $\vec{y}$ is also a minimizer if and only if $A(\vec{y} - \vec{x}) = \zerovec$, i.e., $\vec{y} - \vec{x} \in \nullsp(A)$. So the minimizer is unique if and only if $\nullsp(A) = \{\zerovec\}$, i.e., $A$ has full column rank.
\end{proof}

Thus, if $\vec{x}$ minimizes the squared residual, then
\begin{equation*}
  \ip{A\vec{d}}{A\vec{x}} = \ip{A\vec{d}}{\vec{b}} \qquad \text{for all } \vec{d} \in \K^n.
\end{equation*}
Both directions of the theorem are useful:
\begin{itemize}
  \item Every minimizer satisfies \eqref{eq:ls-orth}. So solving \eqref{eq:ls-orth} finds all minimizers.
  \item To show that a given $\vec{x}$ is a minimizer, it is enough to check \eqref{eq:ls-orth}. We do this for the QR solution in \Cref{sec:verify-qr}.
\end{itemize}
Geometrically, \eqref{eq:ls-pythagoras} is the Pythagorean theorem.

\small When the residual $A\vec{x} - \vec{b}$ is orthogonal to $\range(A)$, \eqref{eq:ls-pythagoras} is the Pythagorean theorem. Every other point $A\vec{y}$ in $\range(A)$ is at least as far from $\vec{b}$.
\end{center}

\paragraph{Geometric meaning.} The vectors $A\vec{d}$, for all $\vec{d} \in \K^n$, are exactly the vectors in $\range(A)$. So the condition says: the residual is orthogonal to every vector in $\range(A)$. In other words, $A\vec{x}$ is the point of $\range(A)$ closest to $\vec{b}$. It is the orthogonal projection of $\vec{b}$ onto $\range(A)$. This is the picture of \Cref{ch:ls}, now with a proof.

\section{What the Optimality Condition Says}

What does the optimality condition mean in concrete cases? The condition only tests the residual against vectors of the form $A\vec{d}$. How much this tells us depends on how many vectors have this form.

\paragraph{Invertible square matrices: solving a linear system.} Let $m = n$ and let $A$ be invertible. Let $\vec{x}$ be a minimizer. By \Cref{thm:ls-optimality}, the residual is orthogonal to every $A\vec{d}$. Since $A$ is invertible, we can choose $\vec{d} = A^{-1}(A\vec{x} - \vec{b})$, so that $A\vec{d} = A\vec{x} - \vec{b}$. Then
\begin{equation}
  0 = \ip{A\vec{d}}{A\vec{x} - \vec{b}} = \ip{A\vec{x} - \vec{b}}{A\vec{x} - \vec{b}} = \norm{A\vec{x} - \vec{b}}^2,
\end{equation}
so $A\vec{x} = \vec{b}$. So for invertible square matrices, least squares is just solving the linear system, and the smallest residual is zero.

\paragraph{Singular or tall matrices: only some directions are tested.} The trick above needs $A\vec{d} = \vec{r}$, where $\vec{r} = A\vec{x} - \vec{b}$ is the residual. If $A$ is singular or $m > n$, then $\range(A)$ is smaller than $\K^m$. If also $\vec{b} \notin \range(A)$, then $\vec{r} \notin \range(A)$, and no such $\vec{d}$ exists. So we only get $\vec{r} \perp \range(A)$, not $\vec{r} = \zerovec$. For example, $A = \begin{psmallmatrix} 1 \\ 0 \end{psmallmatrix}$ and $\vec{b} = \begin{psmallmatrix} 1 \\ 1 \end{psmallmatrix}$ give $x = 1$ and $\vec{r} = \begin{psmallmatrix} 0 \\ -1 \end{psmallmatrix} \ne \zerovec$.

\paragraph{Checking the QR solution.}\label{sec:verify-qr} Now we can prove the informal QR argument from the start of this lecture. Let $A = \hat{Q}\hat{R}$ be a reduced QR factorization, with $\hat{Q}^\ast\hat{Q} = I$. Let $A$ have full column rank, so $\hat{R}$ is upper triangular and invertible. Take $\vec{x} = \hat{R}^{-1}\hat{Q}^\ast\vec{b}$. We check the orthogonality condition, moving $\hat{Q}$ to the right with \Cref{lem:adjoint}:
\begin{equation}
  \begin{aligned}
    \ip{A\vec{d}}{A\vec{x} - \vec{b}} &= \ip{\hat{Q}\hat{R}\vec{d}}{\hat{Q}\hat{R}\hat{R}^{-1}\hat{Q}^\ast\vec{b} - \vec{b}} \\
    &= \ip{\hat{R}\vec{d}}{\hat{Q}^\ast\hat{Q}\hat{R}\hat{R}^{-1}\hat{Q}^\ast\vec{b} - \hat{Q}^\ast\vec{b}} \\
    &= \ip{\hat{R}\vec{d}}{\hat{Q}^\ast\vec{b} - \hat{Q}^\ast\vec{b}} = 0.
  \end{aligned}
\end{equation}
So $\vec{x} = \hat{R}^{-1}\hat{Q}^\ast\vec{b}$ satisfies the orthogonality condition. By \Cref{thm:ls-optimality}, it is a least squares solution, and since $A$ has full column rank, it is the only one. In practice we never form $\hat{R}^{-1}$. We solve the upper triangular system $\hat{R}\vec{x} = \hat{Q}^\ast\vec{b}$ by back substitution.

\section{The Normal Equations}
\label{sec:normal-eq}

The optimality condition holds ``for all $\vec{d}$''. We now turn it into one linear system. The trick is to use the transpose: we apply \Cref{lem:adjoint} to both sides and move $A$ to the right.
\begin{equation}
  \ip{A\vec{d}}{A\vec{x}} = \ip{A\vec{d}}{\vec{b}} \ \ \forall\vec{d} \in \K^n
  \quad\iff\quad
  \ip{\vec{d}}{A^\ast A\vec{x}} = \ip{\vec{d}}{A^\ast\vec{b}} \ \ \forall\vec{d} \in \K^n
  \quad\iff\quad
  A^\ast A\vec{x} = A^\ast\vec{b}.
\end{equation}
The first step is \Cref{lem:adjoint} applied to each side. For the last step, let $\vec{w} = A^\ast A\vec{x} - A^\ast\vec{b}$. The inner product is linear in its second argument, so subtracting the two sides turns the middle condition into $\ip{\vec{d}}{\vec{w}} = 0$ for every $\vec{d} \in \K^n$. ($\Rightarrow$) Then $\vec{w}$ is orthogonal to every vector, including itself. Taking $\vec{d} = \vec{w}$ gives $\norm{\vec{w}}^2 = 0$, so $\vec{w} = \zerovec$, that is, $A^\ast A\vec{x} = A^\ast\vec{b}$. ($\Leftarrow$) If $\vec{w} = \zerovec$, then $\ip{\vec{d}}{\vec{w}} = 0$ for every $\vec{d}$.

So the orthogonality condition is the same as the normal equations. Together with \Cref{thm:ls-optimality}, we get the following theorem.

\begin{theorem}[The Normal Equations]
  \label{thm:normal}
  $\vec{x}$ minimizes $\norm{A\vec{x} - \vec{b}}^2$ if and only if it solves the \emph{normal equations}
  \begin{equation}
    A^\ast A\vec{x} = A^\ast\vec{b}.
  \end{equation}
\end{theorem}

We have turned our system into a square one! The $m \times n$ system $A\vec{x} = \vec{b}$ has become an $n \times n$ system. ``Normal'' means perpendicular: the equation $A^\ast(A\vec{x} - \vec{b}) = \zerovec$ says that the residual is perpendicular to the column space, as in \eqref{eq:normal}.

The normal equations have advantages and one serious drawback.
\begin{itemize}
  \item \emph{Pro:} the system is square, and its matrix $A^\ast A$ is Hermitian (symmetric in the real case). In fact it is positive semidefinite (\Cref{thm:gram}). We can solve such systems with the Cholesky factorization of \Cref{ch:cholesky}, at half the cost of LU.
  \item \emph{Con:} the condition number is squared, $\kappa_2(A^\ast A) = \kappa_2(A)^2$. So forming $A^\ast A$ loses precision when $A$ is ill-conditioned (see the supplement at the end of this lecture).
\end{itemize}

\section{Gram Matrices and Positive Semidefinite Matrices}

Solving the normal equations means solving a system with a matrix of the form $B^\ast B$. (We use the letter $B$ here, so that $A$ is free for the matrix of the system.) So we study such matrices. We start with a larger class.

\begin{definition}[Hermitian and Anti-Hermitian Matrices]
  A matrix $A \in \K^{m \times m}$ is \emph{Hermitian} if $A^\ast = A$, and \emph{anti-Hermitian} (or skew-Hermitian) if $A^\ast = -A$. For $\K = \R$, they are called \emph{symmetric} and \emph{antisymmetric} (or skew-symmetric).
\end{definition}

\begin{proposition}[Eigenvalues of (Anti-)Hermitian Matrices]
  \label{prop:herm-eig}
  All eigenvalues of a Hermitian matrix are real. All eigenvalues of an anti-Hermitian matrix are purely imaginary.
\end{proposition}

\begin{proof}
  Let $A\vec{v} = \lambda\vec{v}$ with $\vec{v} \ne \zerovec$. Then $\vec{v}^\ast A\vec{v} = \lambda\norm{\vec{v}}^2$. We take the complex conjugate of the number $\vec{v}^\ast A\vec{v}$:
  \begin{equation}
    \overline{\vec{v}^\ast A\vec{v}} = (\vec{v}^\ast A\vec{v})^\ast = \vec{v}^\ast A^\ast\vec{v} = \pm\vec{v}^\ast A\vec{v},
  \end{equation}
  with $+$ for Hermitian and $-$ for anti-Hermitian $A$. So $\vec{v}^\ast A\vec{v}$ is real in the first case and purely imaginary in the second. The same holds for $\lambda = \vec{v}^\ast A\vec{v}/\norm{\vec{v}}^2$.
\end{proof}

These matrices behave a lot like complex numbers.
\begin{itemize}
  \item Every square matrix splits into a Hermitian and an anti-Hermitian part, $A = \frac{1}{2}(A + A^\ast) + \frac{1}{2}(A - A^\ast)$. This is like splitting a complex number into its real and imaginary parts.
  \item A second analogy is $z = e^{i\theta}r$ with $r \ge 0$. Its matrix version is the polar decomposition below. It uses the following notion, which we study in detail later in this section: a Hermitian matrix $S$ is \emph{positive semidefinite} if $\vec{v}^\ast S\vec{v} \ge 0$ for all $\vec{v}$.
\end{itemize}

\begin{theorem}[Polar Decomposition]
  \label{thm:polar}
  For every $A \in \K^{m \times m}$, there are a unitary $U$ and a Hermitian positive semidefinite $S$ such that
  \begin{equation}
    A = US.
  \end{equation}
\end{theorem}

\begin{proof}
  Take an SVD $A = W\Sigma V^\ast$ and insert $V^\ast V = I$:
  \begin{equation}
    A = W\Sigma V^\ast = \underbrace{(WV^\ast)}_{U}\underbrace{(V\Sigma V^\ast)}_{S}.
  \end{equation}
  We check the two factors.
  \begin{itemize}
    \item $U = WV^\ast$ is a product of unitary matrices, so it is unitary.
    \item $S = V\Sigma V^\ast$ is Hermitian, since $\Sigma$ is real and diagonal. Also $\vec{v}^\ast S\vec{v} = \sum_i\sigma_i\abs{(V^\ast\vec{v})_i}^2 \ge 0$. \qedhere
  \end{itemize}
\end{proof}

Geometrically, $S$ stretches space along the orthogonal directions given by the columns of $V$. Then $U$ rotates (or reflects) the result. The factor $S$ is always determined by $A$: since $A^\ast A = SU^\ast US = S^2$, $S$ is the positive semidefinite square root of $A^\ast A$. If $A$ is invertible, then so is $S$, and $U = AS^{-1}$ is determined too.

\paragraph{Gram matrices.} A matrix of the form $B^\ast B$ is called a \emph{Gram matrix} (or inner product matrix). Its entries are the inner products of the columns $B_{:,1}, \dots, B_{:,n}$ of $B$ with each other. Using $B\vec{e}_j = B_{:,j}$,
\begin{equation}
  (B^\ast B)_{ij} = \vec{e}_i^\ast B^\ast B\vec{e}_j = \ip{B\vec{e}_i}{B\vec{e}_j} = \ip{B_{:,i}}{B_{:,j}}.
\end{equation}
We see right away:
\begin{itemize}
  \item The diagonal entries $(B^\ast B)_{ii} = \norm{B_{:,i}}^2$ are $\ge 0$.
  \item $B^\ast B = I$ exactly when the columns of $B$ are orthonormal.
\end{itemize}

\begin{definition}[Positive (Semi)definite Matrices]
  A Hermitian matrix $A \in \K^{n \times n}$ is
  \begin{itemize}
    \item \emph{positive semidefinite} if $\vec{x}^\ast A\vec{x} \ge 0$ for all $\vec{x} \in \K^n$;
    \item \emph{positive definite} if $\vec{x}^\ast A\vec{x} > 0$ for all $\vec{x} \ne \zerovec$.
  \end{itemize}
\end{definition}

The main result of this section: Gram matrices and positive semidefinite matrices are the same thing.

\begin{theorem}[Gram Matrices Are Exactly the Positive Semidefinite Matrices]
  \label{thm:gram}
  \begin{enumerate}
    \item $A \in \K^{n \times n}$ is Hermitian positive semidefinite if and only if it is a Gram matrix, i.e., $A = B^\ast B$ for some matrix $B$.
    \item For $B \in \K^{m \times n}$, the Gram matrix $B^\ast B$ is positive definite if and only if $B$ has full column rank.
  \end{enumerate}
\end{theorem}

Item 1 is false for general Hermitian matrices. For example, $\diag(1, -1)$ is symmetric but not a Gram matrix: its second diagonal entry would have to be $\norm{B_{:,2}}^2 \ge 0$. In item 2, the rank condition is on $B$, not on the square matrix $B^\ast B$.

\begin{proof}[Proof of item 1]
  \emph{Gram matrices are Hermitian positive semidefinite.} We have
  \begin{equation}
    (B^\ast B)^\ast = B^\ast(B^\ast)^\ast = B^\ast B, \qquad \vec{x}^\ast B^\ast B\vec{x} = \norm{B\vec{x}}^2 \ge 0.
  \end{equation}

  \emph{Hermitian positive semidefinite matrices are Gram matrices.} We take a square root of $A$ in three steps.
  \begin{enumerate}
    \item \emph{Diagonalize.} By the spectral theorem, $A = U\Lambda U^\ast$, where $U$ is unitary and $\Lambda$ is diagonal with the eigenvalues of $A$ on its diagonal.
    \item \emph{The eigenvalues are $\ge 0$.} They are real by \Cref{prop:herm-eig}. If $A\vec{v} = \lambda\vec{v}$ with $\vec{v} \ne \zerovec$, then $\lambda\norm{\vec{v}}^2 = \vec{v}^\ast A\vec{v} \ge 0$, so $\lambda \ge 0$. (If $A$ is positive definite, the same argument gives $\lambda > 0$.)
    \item \emph{Take square roots.} So we can define $\sqrt{\Lambda} = \diag(\sqrt{\lambda_1}, \dots, \sqrt{\lambda_n})$. We insert $U^\ast U = I$ in the middle:
    \begin{equation}
      A = U\sqrt{\Lambda}\,U^\ast U\sqrt{\Lambda}\,U^\ast = \left(U\sqrt{\Lambda}\,U^\ast\right)^\ast\left(U\sqrt{\Lambda}\,U^\ast\right).
    \end{equation}
    In the last step we used that $\sqrt{\Lambda}$ is real and diagonal, so it equals its conjugate transpose.
  \end{enumerate}
  So $B = U\sqrt{\Lambda}\,U^\ast$ gives $A = B^\ast B$.
\end{proof}

The matrix $B = U\sqrt{\Lambda}\,U^\ast$ is the \emph{matrix square root} $A^{1/2}$. It is not the only choice: for any unitary $V$, $(VB)^\ast(VB) = B^\ast B$. For example, a QR factorization $B = QR$ (\Cref{thm:qr-exists}) gives $A = R^\ast Q^\ast QR = R^\ast R$ with $R$ upper triangular. This is the \emph{Cholesky factorization} of $A$, the topic of the next lecture.

\begin{proof}[Proof of item 2]
  We show the equivalent statement with both sides negated:
  \begin{equation}
    \begin{aligned}
      B \text{ is column rank deficient}
      &\iff \exists\,\vec{x} \in \K^n \setminus \{\zerovec\} : B\vec{x} = \zerovec \\
      &\iff \exists\,\vec{x} \in \K^n \setminus \{\zerovec\} : \norm{B\vec{x}}^2 = 0 \\
      &\iff \exists\,\vec{x} \in \K^n \setminus \{\zerovec\} : \vec{x}^\ast B^\ast B\vec{x} = 0.
    \end{aligned}
  \end{equation}
  By item 1, $\vec{x}^\ast B^\ast B\vec{x} \ge 0$ always. So $B^\ast B$ is not positive definite exactly when $\vec{x}^\ast B^\ast B\vec{x} = 0$ for some $\vec{x} \ne \zerovec$. This is the last line above.
\end{proof}

\paragraph{What this means for least squares.} Putting \Cref{thm:normal,thm:gram} together,
\begin{equation}
  \begin{aligned}
    A \text{ has full column rank} &\iff A^\ast A \text{ is positive definite} \\
    &\iff \text{the normal equations have the unique solution } \vec{x} = (A^\ast A)^{-1}A^\ast\vec{b}.
  \end{aligned}
\end{equation}
This agrees with the uniqueness statement of \Cref{thm:ls-optimality}. We can solve a positive definite system with the Cholesky factorization $A^\ast A = R^\ast R$. It costs about $\frac{1}{3}n^3$ flops, half of LU, and needs no pivoting.

\subsection{Why the Perturbation Argument}

In \Cref{thm:ls-optimality} we moved $\vec{x}$ a little in every direction $\vec{d}$ and used that the value cannot go down. This idea, ``at a minimizer, the first-order change in every direction is $\ge 0$'', works in many other settings:
\begin{itemize}
  \item General differentiable functions: at a minimizer, the gradient is zero.
  \item Problems with constraints: we can no longer replace $\vec{d}$ by $-\vec{d}$, so the result stays an inequality. This leads to variational inequalities and the KKT conditions.
  \item Infinite-dimensional problems, such as finite elements. There, Galerkin orthogonality says that the residual is orthogonal to every test function $v$. This is the same as ``for all $\vec{d}$'' here.
\end{itemize}

\subsection{A Numerical Warning About the Normal Equations}

By \Cref{sec:herm-basics}, the singular values of $A^\ast A$ are the squares of those of $A$. So
\begin{equation}
  \kappa_2(A^\ast A) = \kappa_2(A)^2.
\end{equation}
If $A$ is ill-conditioned, solving $A^\ast A\vec{x} = A^\ast\vec{b}$ loses about twice as many digits as necessary.

The normal equations are faster: forming $A^\ast A$ takes about $mn^2$ flops and Cholesky another $\frac{1}{3}n^3$. This is about half the cost of Householder QR when $m \gg n$. But the speed is only worth it when $A$ is well-conditioned. So in practice we use a QR factorization and solve $\hat{R}\vec{x} = \hat{Q}^\ast\vec{b}$ instead~\cite[Lecture 11]{TB}.
